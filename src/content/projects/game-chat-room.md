# zh
## 專案簡介

在日新軟體擔任前端工程師期間，使用 Vue.js 與 WebSocket 開發並上線遊戲內的即時聊天室，支援快速回覆與貼圖。

玩家進入遊戲時，聊天室會一併開啟。採用這項功能的遊戲產品，尖峰時有數千名玩家同時連線，這個數字指整個遊戲產品的連線人數，並非單一聊天室的同時使用人數。

# en
## Overview

Built and launched an in-game real-time chat room at Neutec using Vue.js and WebSocket, with quick replies and instant stickers.

The chat opens when a player enters the game. The game product using it had thousands of players online at peak. This is the game-wide online population, rather than concurrent users of a single chat room.
