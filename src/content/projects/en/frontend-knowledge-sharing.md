## Overview

Slides prepared for weekly front-end team presentations in 2020–2021, covering JavaScript behaviour, React and TypeScript fundamentals, and comparisons of PixiJS and CSS animation, with code examples to support the explanations.

The slides were built with MDX Deck and Gatsby for viewing in a browser. The collection covers ten topics, with a separate link for each presentation.

### Languages and frameworks

- [TypeScript](https://yc-rainyu.github.io/presentations/public/) covers type inference, annotations, primitive types, unions and interfaces, with a [print view](https://yc-rainyu.github.io/presentations/public/print/).
- [JavaScript this](https://yc-rainyu.github.io/presentation/public/2/) explains this under different calling patterns.
- [Hoisting](https://yc-rainyu.github.io/presentation/public/8/) explains JavaScript declaration-hoisting behaviour.
- [Front-end frameworks](https://yc-rainyu.github.io/presentation/public/6/) and [React from scratch](https://yc-rainyu.github.io/presentation/public/7/).

### Animation and tools

- [Flip clock implementations in Pixi and CSS3](https://yc-rainyu.github.io/presentation/public/1/) compares Canvas and DOM/CSS implementations.
- [Pixi Particle effects](https://yc-rainyu.github.io/presentation/public/4/) introduces particle effects and their parameters.
- [Line charts and prototype-based structure](https://yc-rainyu.github.io/presentation/public/0/).
- [Card flipping and iframes](https://yc-rainyu.github.io/presentation/public/3/).
- [VS Code extensions](https://yc-rainyu.github.io/presentation/public/5/).

Related implementations are collected in [Front-end Visual Experiments](/en/work/frontend-visual-experiments/). The slides retain their original content and package versions.
