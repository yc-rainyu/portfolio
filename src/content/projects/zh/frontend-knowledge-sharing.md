## 專案簡介

整理 2020 至 2021 年於前端團隊每週分享中製作的簡報。內容從 JavaScript 的執行行為、React 與 TypeScript 基礎，到 PixiJS 與 CSS 動畫的實作比較，以程式範例輔助說明。

簡報使用 MDX Deck 與 Gatsby 製作，可直接在網頁瀏覽。內容涵蓋十個主題，各主題保留獨立的瀏覽入口。

### 語言與框架

- [TypeScript](https://yc-rainyu.github.io/presentations/public/)介紹型別推論、型別註記、原始型別、聯合型別與介面，另提供[列印版](https://yc-rainyu.github.io/presentations/public/print/)。
- [JavaScript 中的 this](https://yc-rainyu.github.io/presentation/public/2/)以範例說明不同呼叫方式下的 this。
- [Hoisting](https://yc-rainyu.github.io/presentation/public/8/)說明 JavaScript 宣告提升的行為。
- [前端框架](https://yc-rainyu.github.io/presentation/public/6/)與[從零開始學 React](https://yc-rainyu.github.io/presentation/public/7/)。

### 動畫與工具

- [翻頁時鐘的 Pixi 與 CSS3 實作比較](https://yc-rainyu.github.io/presentation/public/1/)比較 Canvas 與 DOM／CSS 的實作方式。
- [Pixi Particle 粒子效果](https://yc-rainyu.github.io/presentation/public/4/)介紹粒子效果與參數。
- [折線圖與 Prototype 架構](https://yc-rainyu.github.io/presentation/public/0/)。
- [翻牌與 iframe](https://yc-rainyu.github.io/presentation/public/3/)。
- [VS Code Extension](https://yc-rainyu.github.io/presentation/public/5/)。

相關動態實作收在[前端視覺特效實驗](/zh/work/frontend-visual-experiments/)。簡報保留當時的內容與套件版本。
