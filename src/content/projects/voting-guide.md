# zh
## 專案簡介

2023 年 2 月參與 g0v 零時政府的開源選前資訊網站選前大補帖 voting-guide.tw，負責部分前端開發。

網站提供候選人背景、競選資訊與政策立場，供選民在投票前參考。前端使用 Nuxt 3、Vue 3、TypeScript 與 Tailwind CSS，透過 REST API 取得候選人資料與問答內容。

參與時的前端版本包含選民問答頁，區分已回答與待回答的問題，以對話框呈現選民提問與候選人回覆。提問視窗可選擇議題分類、輸入內容並送出，表單按鈕、下拉式選單、文字輸入與問答對話框則拆成可重複使用的元件，另有 Google 登入介面。

# en
## Overview

Contributed to the front-end development of voting-guide.tw, an open-source pre-election information site from the g0v civic tech community, in February 2023.

The project aims to help voters understand candidates' backgrounds, campaign information and policy positions before voting. The front end uses Nuxt 3, Vue 3, TypeScript and Tailwind CSS, with REST APIs for candidate data and questions and answers.

The front-end version from this period includes a voter Q&A page that separates answered and unanswered questions and displays questions and candidate replies in speech bubbles. A question modal supports topic selection, text entry and submission. Buttons, select fields, text areas and question bubbles are organised as reusable components, alongside a Google sign-in interface.
